# Mirrors the gardenio-next config-mirror per-env deny-list (advice ka-0000007027):
# same defense — "never sync a per-env / internal-only artifact" — different target
# (a friend's air-gapped box instead of the gardenio-next mirror).
#
# FORMAT: one POSIX extended-regex (ERE) per non-blank, non-`#` line. The guard
# (`guard_scan` in build-seed-config.sh) matches every line case-INSENSITIVELY
# (grep -iE) against the FINAL, post-redaction text of every bead selected for the
# seed. ANY match FAILS the build — the seed can never ship a leaked internal ref.
#
# This file is the single source of truth for BOTH:
#   1. the guard (build fails on a match), and
#   2. the genericization pass (build-seed-config.sh's REDACT_SUBS maps a subset of
#      these to friend-grade placeholders BEFORE the guard runs, so a keep-redacted
#      body that merely NAMES an internal host is genericized, not rejected).
# A pattern with no genericization rule is fail-closed: a bead that still matches it
# after redaction is DROPPED from the seed by the guard, never silently shipped.
