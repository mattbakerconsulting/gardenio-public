# gVisor runsc checkpoint/restore PoC — design records

These are the design records from the gVisor freeze/thaw PoC that live code still
cites as its design source (coop `rehydrate`/`thaw`, `internal/thawepoch`,
`internal/podmanager/freezethaw.go`, the gVisor e2e scripts). They were moved here
from `gardenio/poc/gvisor-runsc-cr/` when that tree was deleted (gd-Wtw4k6fKwr).

| Doc | What it records |
|---|---|
| [`report.md`](report.md) | Phase-2 freeze/thaw fidelity + overhead benchmark |
| [`restore-through-lifecycle.md`](restore-through-lifecycle.md) | Restore into a placeholder Pod B through the kubelet/CRI lifecycle |
| [`single-container-resume.md`](single-container-resume.md) | Single-container agent resume (fix c) |
| [`multi-container-resume.md`](multi-container-resume.md) | Multi-container (sidecar) resume and the barrier |
| [`rehydration-design.md`](rehydration-design.md) | Post-thaw rehydration contract (thaw epoch, credential/session refresh) |

The PoC harness these docs name by file (`cr-harness.sh`, `bench-*.sh`,
`restore-through-lifecycle.sh`, `restore-into-b.py`, the pod manifests, `results/`,
and the other PoC write-ups such as `prior-art.md`, `phase3-cri-recon.md` and
`poc-shrink.md`) is no longer on `main`. Recover it from the archive tag:

```bash
git fetch origin tag archive/clutter-pre-delete-2026-10-28
git worktree add ../gvisor-poc archive/clutter-pre-delete-2026-10-28
cd ../gvisor-poc/gardenio/poc/gvisor-runsc-cr
```

  [`gardenio/tests/e2e/scripts/gvisor-node/`](../../tests/e2e/scripts/gvisor-node/)
